# Skills

Drop a directory with a `SKILL.md` here (name, description, body) and it is offered to the model when the
description matches the task — no setting to flip. See `builder/tsf/pages/ai-docs/pi.md` section 6.

| Skill | Use |
|---|---|
| `build-state-change/` | An emmett state-change slice: command handler, tests, route |
| `build-state-view/` | An emmett state-view slice: projection, tests, route, migration |
| `build-automation/` | An emmett automation slice: reactor processor and command handler |
| `build-webhook/` | A webhook slice as a Supabase Edge Function |
| `board-change-build/` | Changes made on the event model board |
| `emmett-reference/` | The emmett and dumbo APIs and scaffold helpers as installed in the app |
